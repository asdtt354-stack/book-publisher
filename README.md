# 📚 BookPublisher Pro

**선생님과 일반인을 위한 한국어 책 출판 편집 앱**

> 만든 사람: **박성애** | [EAIM 교육 플랫폼](https://eaim.co.kr)

---

## 소개

BookPublisher Pro는 별도 설치 없이 브라우저에서 바로 실행되는 **단일 HTML 파일 기반 한국어 책 편집기**입니다.  
교사, 작가, 일반인 누구나 쉽게 책을 편집하고 PDF로 출력할 수 있습니다.

---

## 주요 기능

### 편집
- 페이지 자동 생성 (내용 넘침 감지 → 다음 페이지로 자동 이동)
- H1 / H2 / H3 제목 스타일 지원
- 이미지 삽입 (왼쪽 / 오른쪽 정렬, 클릭으로 전환)
- 표 삽입 (Tab 키로 셀 이동, 자동 행 추가)
- 목차 자동 생성 및 페이지 삽입

### 레이아웃
- 판형 선택: B5, A5, 신국판, 크라운판, 46배판, A4
- 홀수 / 짝수 페이지 여백 자동 반전 (안쪽 / 바깥쪽)
- 마스터 페이지: 머리글 · 꼬리글 · 페이지 번호 (`{{페이지}}`, `{{제목}}` 변수)
- 출판 표준 페이지 번호 시스템 (본문 / 앞부속물 / 없음)

### 표지 & 디자인
- 표지 색상 및 이미지 업로드
- 속지 패턴 8종: 민무늬, 도트, 가로선, 격자, 마름모, 물결, 린넨, 대리석
- 뒤표지 + 책등 자동 계산 (페이지 수 × 용지 두께 mm)
- 펼침보기 (앞표지 + 책등 + 뒤표지 스프레드)

### 출판 준비
- 출판 체크리스트 (ISBN, CIP, 납본 등)
- PDF 출력: 3mm 도련 + 재단선 표시
- 로컬 저장 / 불러오기 (`.bookpub` JSON 파일)
- 자동 저장 (브라우저 localStorage)

### AI 보조 (Gemini API)
- 맞춤법 교정
- 문체 다듬기
- 내용 요약
- 제목 제안

## 설치 방법

설치 불필요. 파일 하나만 있으면 됩니다.

1. `book-publisher.html` 파일을 다운로드합니다.
2. 파일을 **더블클릭**하거나 Chrome / Edge 브라우저로 엽니다.
3. 바로 사용 가능합니다.

> **권장 브라우저:** Google Chrome 또는 Microsoft Edge (최신 버전)

---

## Gemini API 키 발급 방법

AI 기능(맞춤법, 문체 다듬기, 요약, 제목 제안)을 사용하려면 무료 Gemini API 키가 필요합니다.

### 1단계 — Google AI Studio 접속
[https://aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에 접속합니다.

### 2단계 — Google 계정 로그인
기존 Google 계정(Gmail 등)으로 로그인합니다.  
계정이 없다면 무료로 만들 수 있습니다.

### 3단계 — API 키 생성
1. **"API 키 만들기"** 버튼을 클릭합니다.
2. 프로젝트를 선택하거나 새 프로젝트를 만듭니다.
3. 생성된 키(`AIza`로 시작하는 문자열)를 복사합니다.

### 4단계 — 앱에 키 입력
1. BookPublisher Pro를 열고 왼쪽 패널에서 **"AI"** 탭을 클릭합니다.
2. **"Gemini API 키"** 입력란에 복사한 키를 붙여넣습니다.
3. 저장 버튼을 클릭하면 브라우저에 안전하게 저장됩니다.

> **참고:** API 키는 본인 브라우저에만 저장되며 외부로 전송되지 않습니다.  
> Gemini API는 일정 사용량까지 **무료**로 제공됩니다.

## 사용 방법

### 기본 편집

| 작업 | 방법 |
|------|------|
| 새 페이지 추가 | 툴바 **"+ 페이지"** 버튼 |
| 제목 입력 | 페이지 클릭 후 H1 / H2 / H3 선택 |
| 이미지 삽입 | 툴바 **"이미지"** 버튼 → 파일 선택 |
| 표 삽입 | 툴바 **"표"** 버튼 |
| 셀 이동 (표) | `Tab` 키 |
| 목차 생성 | 툴바 **"목차"** 버튼 |

### 판형 및 여백 설정

1. 오른쪽 패널에서 **판형**을 선택합니다.
2. 상하좌우 여백을 mm 단위로 입력합니다.
3. **"적용"** 버튼을 클릭합니다.

### 표지 만들기

1. 왼쪽 패널 **"표지"** 탭 클릭
2. 제목, 부제목, 저자 입력
3. 배경 색상 선택 또는 이미지 업로드
4. 책등 두께는 페이지 수에 따라 자동 계산됩니다.

### 저장 및 불러오기

- **저장:** 툴바 **"저장"** → `.bookpub` 파일로 내 컴퓨터에 저장
- **불러오기:** 툴바 **"열기"** → 저장된 `.bookpub` 파일 선택
- **자동저장:** 편집 내용이 브라우저에 자동으로 저장됩니다.

### PDF 출력

1. 툴바 **"PDF 출력"** 버튼 클릭
2. 3mm 도련과 재단선이 포함된 인쇄용 PDF가 생성됩니다.
3. 브라우저 인쇄 창에서 **"PDF로 저장"** 을 선택합니다.
