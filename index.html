📚 출판 안내 — ISBN 발급 가이드

부크크는 사업자 등록 없이 누구나 ISBN을 받고 POD(주문형 인쇄) 출판까지 할 수 있는 플랫폼입니다. 선생님·학생 누구나 가능! 모두 무료입니다.

1
부크크 회원가입 무료
부크크 사이트에서 일반 회원가입합니다.
사업자 등록증 불필요 — 개인 누구나 가능!
🔗 bookk.co.kr 바로가기
2
원고 PDF 업로드
이 편집기에서 PDF 출력으로 저장한 파일을 부크크에 업로드합니다.
표지(앞/뒤)와 본문 PDF를 각각 업로드하면 됩니다.
판형: A4, B5, A5 등 선택 가능
3
ISBN 자동 발급 무료
출판 신청 시 부크크가 ISBN을 대행 발급해드립니다.
별도 출판사 등록 없이 979-11로 시작하는 ISBN 자동 부여!
발급 기간: 보통 1~3일 이내
4
POD 인쇄 & 판매
주문이 들어올 때마다 인쇄하는 POD(주문형 출판) 방식으로 재고 부담 없음!
부크크 서점 등록 + 교보문고·예스24 등 온라인 서점 유통 가능
인세는 판매가의 일정 % 자동 정산
💡 부크크 vs 전통 출판 비교
부크크: 사업자 불필요, ISBN 대행, POD 인쇄, 빠른 출판 ✅
전통 출판: 출판사 등록 필요, ISBN 직접 신청, 대량 인쇄에 유리

국내에서 책을 출판하려면 출판사 등록과 ISBN 발급이 필요합니다.
아래 4단계를 순서대로 진행하세요. 모두 무료입니다.

1
출판사 등록 무료
사업장 관할 구청 또는 군청에 방문하여 출판사 신고를 합니다.
필요 서류: 신분증, 출판사명·주소·대표자 정보
처리 기간: 즉시 ~ 2~3일 이내 (지역마다 상이)
2
국립중앙도서관 ISBN센터 회원가입
출판사 등록 완료 후 ISBN센터에서 출판사 회원으로 가입합니다.
출판사 신고 확인증(또는 사업자등록증) 스캔본 업로드 필요
🔗 isbn.nl.go.kr 바로가기
3
ISBN 신청 무료
로그인 후 [자료 신청 → 단행본 ISBN 신청] 메뉴에서 신청합니다.
입력 항목: 책 제목, 저자명, 출판사, 출판 예정일, 도서 분야, 판형 등
발급 기간: 신청 즉시 자동 발급 — 13자리 숫자 ISBN 부여
4
바코드 생성 및 뒤표지 삽입
발급된 ISBN으로 EAN-13 바코드를 생성하여 뒤표지에 삽입합니다.
바코드 형식 예시: 978-89-XXXXX-XX-X
무료 생성 사이트: barcode.tec-it.com 또는 온라인 EAN-13 생성기 검색
💡 출판 후 납본 의무 (저작권법)
출판일로부터 30일 이내에 국립중앙도서관과 국회도서관에 각 2부씩 납본해야 합니다.
ISBN센터 사이트에서 전자납본도 가능합니다.
🖼 이미지 일괄 업로드
페이지 배치 방식
※ 현재 선택된 페이지 다음부터 순서대로 삽입됩니다
❓ 사용 가이드 — 책 편집기
1
판형 선택
상단 드롭다운에서 B5·A5·A4 등 선택. 그림책은 사용자 정의 → 297×210 (A4 가로)를 추천해요.
2
폰트 / 크기 / 행간
전체 크기 — 페이지 전체 기본 글자 크기 조정
선택글자 크기 — 드래그한 텍스트만 크기 변경
행간: 1.6~2.2 중 선택 (그림책은 1.8~2.0 추천)
3
책 제목 입력
툴바 왼쪽 입력란에 책 제목을 입력하면 저장 시 해당 이름으로 파일이 저장돼요.
1
페이지 추가 / 삭제 / 이동
오른쪽 패널 페이지 작업에서:
+ 빈 페이지 추가 / + 속지 페이지 추가 / × 삭제 / ↑↓ 순서 이동
2
속지 패턴
상단 속지 버튼 → 패턴(도트·격자·물결 등)과 색상 선택 → 적용
3
페이지 번호 섹션
오른쪽 패널에서 섹션 설정:
본문 (1,2,3…) / 서문 (i,ii,iii…) / 번호 없음
1
제목 스타일
H1 가장 큰 제목 / H2 중간 제목 / H3 소제목
커서를 줄에 놓고 H1~H3 클릭하면 적용돼요.
2
텍스트 꾸미기
텍스트 드래그 후:
B 굵게 / I 기울임 / U 밑줄
🎨 글자 색상 / 🖌 형광펜 배경색
≡← 왼쪽 / ≡ 가운데 / ≡→ 오른쪽 정렬
3
머리글/꼬리글
마스터 버튼 → 책 제목·페이지 번호 자동 삽입 설정
변수: {{페이지}} {{제목}}
1
🖼 이미지 — 본문 삽입
이미지를 본문 안에 삽입. 클릭하면 왼쪽/오른쪽 정렬 전환 가능.
2
🖼 전체채우기 — 배경 이미지
이미지가 페이지 전체를 꽉 채워요. 그림책 장면에 적합!
페이지 오른쪽 위 ✕ 배경 제거로 삭제 가능.
3
🖼 일괄업로드 — 여러 장 한꺼번에
이미지 여러 장 선택 후 배치 방식 선택:
그림→글 / 글→그림 / 그림만 / 그림+글 한 페이지
4
📱 QR코드 삽입
YouTube·Google Photos URL 입력 → QR코드 자동 생성 삽입
인쇄된 책에서 스캔하면 영상 바로 재생!
1
앞표지 디자인
앞표지 버튼 → 제목·부제목·저자·출판사 입력
배경색 또는 이미지 업로드 / Gemini AI로 표지 이미지 자동 생성!
2
뒤표지 디자인
뒤표지 버튼 → 책 소개문·저자 소개·ISBN·정가 입력
책등 너비 자동 계산 / 펼침 보기로 전체 확인 가능
3
목차 자동 생성
목차 버튼 → 본문의 H1·H2·H3 제목을 자동으로 수집해서 목차 페이지 생성!
1
파일 저장 / 불러오기
저장 → 책제목.bookpub 파일로 내 PC에 저장
열기 → 저장한 파일 불러오기
💡 선생님마다 본인 파일명으로 저장하면 서로 안 겹쳐요!
2
PDF 출력
PDF 출력 버튼 → 인쇄 창에서 "PDF로 저장" 선택
도련(3mm) 포함, 재단선 자동 표시
부크크 업로드용 PDF로 바로 사용 가능!
3
출판 안내
출판 안내 버튼 → 부크크(사업자 불필요) 또는 전통 출판사 등록 방법 안내
ISBN 발급부터 POD 인쇄까지 4단계로 정리!
